# BCN Fabric Platform

Microsoft Fabric implementation for sales ingestion, Lakehouse engineering, analytics, demand prediction, and orchestration.

## Fabric Git integration

The `fabric/` folder is the target directory for Fabric workspace item definitions. Connect the Fabric development workspace to this repository's `main` branch and this folder, then use **Commit to Git** to export the workspace items.

## Intended lifecycle

`GitHub → bcn-dev → bcn-test → bcn-prod`
